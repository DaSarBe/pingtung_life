# 屏東人生

在瀏覽器裡過一段屏東市的開放生活。你租在屏東火車站附近的雅房，可以走路、騎機車、開車，在同一座城裡打工、吃飯、跟人說話。也可以闖一點卡通式的禍，通緝星會上升，警察會追。

存款以新台幣計算。薪水、票價、油錢和房租是為了讓一天玩得下去而簡化的數字，不是真實市價。

## 怎麼開始

不需要安裝、不需要建置，也不需要網路。

1. 打開這個資料夾。
2. 雙擊 `index.html`，用瀏覽器開啟。
3. 手機玩時，把檔案傳過去，或在同一個區域網路用下面的方式開。

如果瀏覽器不讓網頁在本機檔案裡存檔，可以在資料夾開一個小型伺服器：

```bash
python3 -m http.server 8765
```

然後打開 `http://127.0.0.1:8765`。

電腦和手機都能玩。有 3D 時整頁是城市；瀏覽器沒有 WebGL 時，改用按鈕辦事。

## 怎麼玩

- 畫面上有存款、體力、飢餓、心情，以及信用和路子。
- 鍵盤 WASD 或方向鍵、左下角搖桿、點地面移動。拖曳轉動鏡頭。靠近金色光點，按下面的按鈕、E、Enter 或空白鍵。
- 有自己的車而且有油時，按「上車」。油在南油加油站加。別人的車騎完或沒油就留在路邊。
- 中正路貫南北，自由路貫東西。屏東火車站、屏東夜市、千禧公園、勝利星村、太平洋百貨、縣政府與六堆客家文化園區、屏東大學、高屏溪、檳榔園、往東港的漁港都在這張路上。
- 火車站可以花 $120 去高雄晃九十分鐘再回來。公車站花 $40 直接換地方。
- 右上角「今日」看關係和最近發生的事，「委託」看支線。

### 打工

每一趟先玩小遊戲，薪水大約是標價的六到十二成。放棄不算班、沒有薪水。每種一天最多三班。

- 8-12 超商店員
- 外送：得先有機車或汽車
- 檳榔園
- 漁港幫工

### 生活

早餐、夜市肉圓、青草茶、超商飯糰、百貨餐廳、大學自助餐都能補飢餓。肚子空了會去診所，有錢就扣錢。

第 7、14、21 天結束時繳房租 $2,800。繳不出來，這局結束。睡覺會再問一次。空著肚子過夜會掉體力和心情。體力或心情在過夜後掉到 0 也會結束。

大順機車 $2,800，可以加加速和油箱。大發汽車 $14,000。

### 人

夜市的阿霞、大學的阿德、六堆的春嬌、溪邊的阿龍。多說話會解開拍照、送文件、套圈、溪邊比賽，以及送一個封好的紙箱。

### 闖禍

街上有沒鎖的機車和汽車、超商和百貨可以順手拿東西、紅燈和測速照相、推開路人、巷口茶室晚上可以小賭或出老千。這些都是按按鈕，接著通緝星上升。星星多了警察會追，抓到會罰款、喝茶，或留到早上。信用高時，第一次闖紅燈或超速先警告。擺脫警察一段時間，星星會掉。

沒有寫實的作案過程，也沒有血腥畫面。

## 存檔

進度自動存在這台瀏覽器。存檔鍵是 `pingtung-life-save-v1`，排行榜是 `pingtung-life-board-v1`。清除瀏覽器資料時會一起消失。存款排行只留這台裝置的前 10 名。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面結構與文字 |
| `css/style.css` | 介面外觀 |
| `js/game.js` | 規則、打工、車輛、通緝、存檔 |
| `js/shift.js` | 超商、外送、檳榔園、漁港、套圈 |
| `js/world.js` | 屏東街道、行人、車流、警察與鏡頭 |

程式裡的變數用英文，註解和畫面文字用繁體中文。

想調難度，改 `js/game.js` 裡的 `RULES` 和 `JOBS`。想改城市，改 `js/world.js` 的 `buildCity`。
