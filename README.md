# 屏東人生

在瀏覽器裡玩的開放世界生活模擬。場景在虛構的屏東市，往南有一條沿海道路可以開到墾丁。白天可以上班、外送、開店，晚上可以逛夜市；另一條路則是卡通化的街頭競賽與地盤記號，最後變成「屏東的夜」。沒有寫實的犯罪教學，也沒有血腥畫面。

存款以新台幣計算。薪水、票價和房租是為了讓一天玩得下去而簡化的數字，不是真實市價。

## 怎麼開始

不需要安裝套件，也不需要建置。因為程式用了 ES 模組，請用本機伺服器開啟，不要用 `file://`：

```bash
python3 -m http.server 8765
```

然後開啟 `http://127.0.0.1:8765/`。電腦和手機都能玩。

## 操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 移動 | WASD 或方向鍵 | 左下虛擬搖桿（左右跟畫面一致） |
| 轉視角 | 在畫面左右拖曳 | 在畫面空白處左右滑動 |
| 衝刺／加速 | Shift 衝刺，空白鍵加速 | 右側「加速」（走路時會衝刺） |
| 互動 | E | 「互動」 |
| 上下車 | F | 「乘車」 |
| 喇叭 | H | — |
| 大地圖 | M | 選單裡的大地圖 |
| 暫停 | Esc | 右上角「選單」 |

畫面上會一直顯示現金、時間、體力、通緝星和目前目標，右上角是小地圖。目標旁有方向盤與「正前方／正右方」這類文字；目標不在畫面裡時，螢幕邊緣也會出現箭頭。手機直向與橫向都留了瀏海與手勢區的安全邊距，按鈕約 64–76 像素。虛擬按鍵在窄螢幕或觸控裝置會自動出現，也可以在設定裡強制開關。

## 時間

遊戲時鐘固定每真實一秒走一分鐘（一天約 24 分鐘）。走路、騎車、開車都不會改變這個速度。睡覺、關進派出所，以及少數劇情，才會把時間往前跳。

## 怎麼玩

新遊戲從屏東車站前開始，現金 $1,600。先去找房東陳桑，再去夜市找阿霞。

- **正路**：打工、外送、在勝利星村租店、去墾丁贊助黑鮪魚季。結局是「屏東好店長」。
- **夜路**：跟阿龍走。街頭賽、卡通塗鴉、送鳳梨酥箱、找三個夥伴，再帶著四顆通緝星回來。結局是「屏東的夜」。

結局之後可以自由遊玩。支線一直都在：夜市套圈圈、射氣球、外送、中正路街頭賽、隨機事件、黑鮪魚季（開局前六天，墾丁有攤）、東港迎王（每天傍晚隊伍會經過）。路人偶爾會說台語，例如「吃飽未」「哩賀」。

通緝星會招來警察。他們會沿著道路找路，星數高時會側面包抄、在前方設路障；五顆星會出現直升機，躲進騎樓可以暫時脫離視線。被抓住會罰款、時間跳過六小時，然後在派出所醒來。這是誇張的卡通追逐，不是現實教學。

紅色機車停在租屋處樓下。靠近其他機車或汽車也可以騎走，搶車會加星。往南出城，沿著海岸公路可以開到墾丁。城裡有屏東火車站、屏東夜市、千禧公園、勝利星村、太平洋百貨等地標。

## 音樂

所有音樂與音效都是這個專案自己用 Web Audio 即時合成的，沒有使用第三方音檔或取樣。場景會自動交叉淡入（約 1.35 秒）：標題、白天市區、夜晚、夜市、追逐、派出所、騎車、家裡、墾丁、節日。追逐時有警笛，騎車時有引擎聲。設定裡可以調音樂、音效，也可以靜音。

## 存檔

存檔在瀏覽器的 `localStorage`：

- `pingtung-life-save-v1`：進度（位置、金錢、時間、章節、通緝、進行中的差事）
- `pingtung-life-board-v1`：設定與紀錄（音量、靜音、虛擬按鍵、結局、街跑成績）

每 20 秒自動存一次。切到背景（`visibilitychange`）或頁面關閉（`pagehide`）也會存。舊版若把金錢寫成 `cash`／`dollars`、時間寫成 `hour`、位置寫成 `pos` 或 `position`、路線寫成 `crime`／`underworld`，讀檔時會轉成現在的格式，鍵名維持不變。

外送與比賽的倒數在背景暫停，回到遊戲再接續，不會因為切換分頁而逾時。清除瀏覽器資料時，存檔會一起消失。

## 畫面

自製的 WebGL2 渲染，低多邊形建築、地標、行人、機車、汽車、警車與直升機。有白天與夜晚、窗戶與路燈發光、海面。遠處區塊會換成較簡的模型並做視錐剔除，手機上會降低解析度，目標是維持可玩的幀率。
